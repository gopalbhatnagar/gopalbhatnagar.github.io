# Sample Slot — PixiJS Commercial-Style Slot Demo

Upgraded portfolio prototype using **PixiJS 8 + TypeScript + Vite**.

### Included
- 5×3 reels with distinct reel strips
- 20 visual paylines and winning-line highlight
- Sequential reel stopping with motion-style animation
- Wild substitution
- Scatter → 8 Free Spins
- Bonus Pick screen
- Win flash / presentation effects
- Bet controls, Auto Spin, Sound toggle, Reset
- Responsive layout for desktop and mobile

### Run locally
```bash
npm install
npm run dev
```

### Production build
```bash
npm run build
```

This is a **portfolio game-development demo**. It is not a real-money gambling implementation and has no payment/account/backend wagering system.
